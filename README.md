# Student Spring Boot Application

A Student Management REST API built using Java and Spring Boot.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API

## Features

- Create Student
- Update Student
- Get Student Details
- Student Validation
- Exception Handling
- Logging
- MySQL Database Integration

## How to Run

1. Clone the repository

git clone https://github.com/AKIF3917/Student-SpringBoot.git

2. Open the project in IntelliJ IDEA.

3. Configure MySQL in application.properties.

4. Run StudentApplication.java
